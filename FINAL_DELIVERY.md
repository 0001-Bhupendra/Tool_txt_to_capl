✅ WHAT GETS EXTRACTED
═══════════════════════════════════════════════════════════════════════════════════

From each PDF test case:

PRE-CONDITION (Initial Setup)
  • si_sys_* signals (system signals)
  • Proxy_* signals (proxy signals - NOW INCLUDES ALL!)
  • Initial values and configuration
  • Typical: 3-7 items

STIMULATION (Test Action)
  • Test description
  • Steps taken
  • What the test does
  • Typical: 1 description + actions

EXPECTED RESULTS (Test Outcomes)
  • XCP_sys_* signals (expected signals)
  • so_sys_* signals (output signals)
  • Proxy_* signals (proxy results)
  • Expected values after test
  • DTC indicators if present
  • Typical: 10-15 items

POST-CONDITION (Final State)
  • Final system state
  • Cleanup actions
  • si_sys_* signals (final values)
  • Typical: 3-5 items


TOTAL EXTRACTED PER TEST CASE: 7-11 items (minimum)
