✅ TROUBLESHOOTING FOR YOUR TEAM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: "RUN_CONVERTER.bat won't open"
A: Right-click it → "Open with..." → Choose Python → Run

Q: "Python is not installed"
A: Download from https://www.python.org/
   Run installer, check "Add Python to PATH"
   Try RUN_CONVERTER.bat again

Q: "Port 8501 is already in use"
A: Close other Streamlit apps or use different port:
   Open RUN_CONVERTER.bat in notepad
   Change last line to add: --server.port=8502

Q: "Extraction is slow"
A: Normal! PDFs are complex. 1 PDF = 2-5 seconds.
   For 100+ PDFs, use batch_pdf_converter.py from command line

✨ WHAT GETS EXTRACTED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Pre-Condition:
  - Initial system setup
  - Signal values: si_sys_*, Proxy_* 
  - Typical: 3-7 items

Stimulation:
  - Test action description
  - What the test does
  - Typical: 5-7 steps

Expected Results:
  - Signals after test: XCP_sys_*, so_sys_*, Proxy_*
  - Expected values
  - DTC indicators
  - Typical: 10-15 items

Post-Condition:
  - Final system state
  - Cleanup actions
  - Signal values
  - Typical: 3-5 items
